LongBox — frontend bundle not built

This placeholder is what gets baked into the binary when cargo build runs without first building the SvelteKit frontend. The Docker build does this for you; local dev needs one extra step. 

cd longbox-frontend
pnpm install
pnpm build
cd ..
cargo build --release -p longbox-web

pnpm build writes the static bundle into longbox-web/frontend-dist/, where rust-embed picks it up at compile time. The generated _app/ directory and favicon.ico are gitignored; only this file is tracked.
